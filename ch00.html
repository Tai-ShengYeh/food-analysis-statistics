0.1 這門課到底在學什麼？（一句話版本）

「把食品分析的數據算對，並且把實驗設計好。」

想像你畢業後到食品廠或檢驗公司上班，主管跟你說：

  1. 「你量出來的數據可不可信？誤差多大？誰說的？」→ 這是 Part 1＋2：數據品管統計與量測不確定度（Ch1–Ch11）
  2. 「這台兩百萬的儀器為什麼測不準？去查。」→ Ch12 進階案例
  3. 「幫公司把配方成本降 3%，順便把營養標籤做出來。」→ Ch13 配方計算
  4. 「新萃取製程交給你，用最少的實驗找到最佳條件。」→ Ch14 實驗設計

這四件事就是本課程的全部。每一章都是其中一小步，學完你就能獨立完成上面所有任務。

📘 Part 1 數據品管統計（Ch1–Ch5）

名詞白話一句話日常比喻
平均數 mean一組數據「大家合起來的共識」＝加總÷個數全班期中考平均分數
標準差 SD數據彼此「合不合群」：越小越整齊同學分數都差 2 分 vs 差 30 分
變異係數 CV%把散布換算成「相對於平均的百分比」，方便跨單位比較身高差 3 cm 和體重差 3 kg 不能直接比大小
準確度 vs 精密度打中靶心＝準確；彈著點集中＝精密（兩者獨立）見 Ch1 的四個靶圖
常態分配大多數量測誤差「中間多、兩邊少」的鐘形全班身高分布
信賴區間 CI「真值最可能落在這個範圍」的專業講法天氣預報「降雨機率 70%」
LOD / LOQ儀器「聽得到」與「量得準」的門檻濃度在吵雜餐廳：聽得到≠聽得懂
管制圖每天畫一點監控方法是否在正常軌道每天量體重記錄，突然連續上升＝警訊
標準曲線／迴歸用已知濃度畫直線，反推未知樣品濃度用身高與鞋子尺碼的對照表猜身高
r²點有多貼近直線（0~1），愈接近 1 愈好—
異常值 outlier明顯不合群、可能是手滑的數據全班 60–80 分，有人考 5 分
有效數字報告該寫幾位（不是越多越專業）體重計不會顯示 63.48291 kg

📗 Part 2 量測不確定度（Ch6–Ch11）

名詞白話一句話日常比喻
系統 vs 隨機誤差固定偏一邊 vs 上上下下的誤差體重計永遠多 0.5 kg vs 站姿不同
不確定度 U專業的「±多少」：真值的合理範圍導航「25 ± 5 分鐘」
GUM 四步驟國際標準流程：定義→找來源→量化→合成做菜的標準作業流程
Type A / Type B用重複實驗算的 vs 用證書規格換算的親身試吃 vs 看標籤
矩形/三角/常態分布只知道「±a」時的三種換算假設，結果不同三種不同公平性的骰子
合成不確定度 uc把各來源的小誤差「平方和開根號」合體直角三角形：兩股求斜邊
涵蓋因子 k=2乘 2 把 uc 變成 95% 信賴的區間 U—
符合性判定結果±U 與法規限值的四種相對位置足球壓線：整顆過線才算進球
Monte Carlo電腦模擬幾萬次代替困難的數學擲骰子一萬次估機率
Kragten 法一次只動一個誤差來源，看誰貢獻大控制變因的排查法

名詞白話一句話日常比喻
中間精密度不同天/人/儀器之間的長期變異不同廚師煮同一道菜
基質效應樣品裡的其他成分干擾儀器訊號湯太濁了，看不到杯底
同位素內標 SIL-IS化學性質相同的「雙胞胎」替你分擔干擾長得一模一樣的替身演員
回收率 recovery加已知量的標準品，看能收回多少%轉帳 100 元測試，看收到幾元
FDC 資料型USDA 免費資料庫的五種資料來源，品質定位不同官方實測 vs 廠商自述

MSNF非脂乳固形：牛奶扣掉水和脂肪剩下的精華—
線性規劃 LP在限制條件下找最便宜組合，最佳解在端點便當配菜省錢法

overrun冰淇淋打入的空氣比例打發鮮奶油會變大

0.5 如何使用本站（10 分鐘設定）

  1. 到 cran.r-project.org 下載並安裝 R（免費，一路下一步）
  2. 到 posit.co/downloads 安裝 RStudio Desktop（免費的「Word for R」）
  3. 開 RStudio → File → New File → R Script（新檔案）
  4. 從各章的程式碼區塊按「複製程式碼」→ 貼上 → 游標放某行按 Ctrl+Enter 執行該行；Ctrl+Alt+R 整段執行
  5. 執行結果出現在左下 Console——出現紅字先別慌，多半是少貼了前幾行，整段重貼一次即可
  6. 每章讀完做「📝 隨堂測驗」，錯的題目會顯示詳解
💾 版本與安裝提醒 全部課程不需要安裝任何套件（Ch14 的選讀段除外，會特別註明）。 R 版本 4.x 皆可；螢幕解析度不限；Windows/Mac 皆可執行。 遇到任何錯誤訊息，把整段錯誤複製下來問老師或搜尋——看懂錯誤訊息也是課程訓練的一部分。
